### 🎓 Nexa Ed: infrastructure for modern school software
APIs, SDKs and tools so developers can build enrollment, payments, document processing and student records into any school app, in minutes instead of months.

| Package | What it does |
|---------|--------------|
| [`@nexa-ed/sdk`](https://github.com/Nexa-ed/sdk) | Typed core client: files, documents, payments, services, webhooks |
| `@nexa-ed/react` | React components and hooks |
| `@nexa-ed/next` | Next.js adapter that mounts every route handler in one call |
| `@nexa-ed/node` | Express, Fastify and Hono adapters |
| `@nexa-ed/convex` | Convex schema fragments and handler factories |
| `create-nexaed-app` | CLI scaffolder: a new school app in seconds |

📚 Docs: [docs.nexa-ed.com](https://docs.nexa-ed.com) · ⭐ SDK: [Nexa-ed/sdk](https://github.com/Nexa-ed/sdk)

### 🧩 Fusion Stack: a visual stack scaffolder
Pick your frontend, backend, auth and email provider in an interactive builder, then get a pre-wired, TypeScript-ready project with one command: `pnpm create fusion-stack@latest`.
Built as a Turborepo monorepo (Next.js builder, Fumadocs site, `@clack/prompts` CLI). [Repo](https://github.com/NexiumLabs/fusion-stack) · [Docs](https://fusion-stack-docs.vercel.app)
